# Store Assets

Screenshots and promotional images for browser extension stores.

## Required assets

### Chrome Web Store
- Screenshots: 1280x800 or 640x400 (1-5 images, PNG or JPEG)
- Small promo tile: 440x280
- Icon: 128x128 (already in `public/icon/icon-128.png`)

### Firefox Add-ons (AMO)
- Screenshots: any reasonable size (1-5 images, PNG or JPEG)
- Icon: 128x128 or 64x64 (already in `public/icon/`)

### Edge Add-ons
- Screenshots: 1280x800 or 640x400
- Logo: 300x300

## Suggested screenshots

1. Popup showing ratings for a well-known film (e.g. Inception)
2. Context menu "Get movie rating" on selected text
3. Options page with API key fields
4. Badge showing aggregate score on toolbar icon
